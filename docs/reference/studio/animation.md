# Original Studio animation playback

Reviewed 2026-09-27 against the working tree. The [Studio audit](../../component-audit/studio.md) is the feature-status and actionable-backlog index; this page records the narrower source contract and its evidence.

The normal Studio animation path resolves the saved `(group, category, no)` through the recovered `Anime_*` tables. Each executable catalog row carries a hash-verified converted controller state, exact source state ID, clips and bindings. An unknown catalog identity never aliases an action-game idle animation.

`OCIChar.LoadAnime`, its speed/pattern setters, `OnSavePreprocessing`, `CharAnimeCtrl`, and the female/male load paths establish these behaviors:

- Load the catalog controller and play its named state at the saved normalized time. The Animator scalar speed is the saved `animeSpeed`; controller state speed is a separate multiplier.
- Normal catalog entries set body height. They do not apply saved `motion` or H-only option parameters. Those fields remain preserved in scenes without incorrectly affecting a normal controller.
- Authored looping clips wrap their sample phase while retaining the normalized loop counter. Forced nonlooping playback restarts at zero in LateUpdate when time reaches one and discards overshoot for that update.
- `Tools/reverse/animation_assets.py` records a clip's serialized `m_CycleOffset` as `cycleOffset`, but converts nothing while `m_LoopBlend` is true: every candidate Unity loop-pose rule was measured against the private six-phase probe of `m_Lewd_00_01` (catalog `0/14/13`, clip cycle offset 0.5) and none reached the 0.0001 tolerance — 0.0295643 for component-wise `value(u) + (value(0) − value(1))·u`, 0.0651397 for the quaternion-channel `slerp(identity, q(0)·inverse(q(1)), u)·q(u)`, 0.4099749 for its right-multiplied pairing, 0.2202807/0.4067154 for the same two with `u` measured before the cycle offset, 0.2801431 for cycle-offset-only sampling, 0.0295643 for the component-wise correction with the corrected quaternion renormalized before use, and 0.2005066 for that variant with `u` taken before the cycle offset. All seven stay on record. A 2026-10-01 re-measurement attributed every correction residual to exactly five passive bones — `cf_pv_shoulder_L/R`, `cf_pv_waist_L/R` and `cf_pv_hips` (all ≤0.0000018 elsewhere), which refutes a root- or motion-node-only correction: correcting `cf_j_root` or `cf_pv_root` alone leaves the raw 0.255855 — and an `m_LoopBlend*` channel-named candidate is vacuous because `m_LoopBlendOrientation`, `m_LoopBlendPositionY` and `m_LoopBlendPositionXZ` are all false on this clip (its motion-node name is not serialized). The clip's position channels need exactly the additive `value(u) + (value(0) − value(1))·u` to five decimals, while its quaternion channels need a local right-multiplied rotation power `q_raw(u)·D^u` with `D = inverse(q(1))·q(0)`: that pairing measures 0.0023087 — the new best — the power alone with raw positions 0.0443834, the same power left-multiplied or with the reversed endpoint delta 0.0651397/0.449663/0.409975/0.351119, a component-wise correction over each curve's own span 0.0295646, a power built from the serialized `m_ValueArrayDelta` quaternion 1.536763, and a loop-pose frame-pair mean delta is identically zero because the curves obey `conj(q(t)) = q(stop − t)`. Fitting `D` freely per bone leaves 0.000048–0.000743 for right multiplication against at least 0.0059 for any left-multiplied form, so the side and axis are right but the needed angle carries a per-bone constant scale of 1.003–1.019 that no serialized quantity provides. Nothing reached 0.0001, nothing was adopted or special-cased, and the rejection message now quotes the best 0.0023087.
- Native evaluation runs at a deterministic 60 Hz clock. Incremental playback caches only completed step boundaries; fractional tails never accumulate into later frames. State/height changes and seeks reset the cache, and failed plug-in transactions restore it. This keeps live clock cost independent of scene age while retaining bit-identical fresh samples. Sample animation on the customized/ABMX baseline, restore source kinematic activation/root resets, apply saved/edited FK, then run the configured IK solver. Attachments and guides query that same final pose.
- Original-scene export patches animation catalog IDs, speed, pattern, force-loop, options and evaluated normalized time in their bounded original byte spans. Other records, card identities, order and plug-in trailers remain unchanged. Native saves also retain the current evaluated animation state.

`Tools/reverse/studio_animation.py` extracts normal catalog rows and converts serialized Transform clips locally. It handles streamed initialization samples at `-FLT_MAX`, timed cubic keys, dense samples with an authored begin time, constant curves and flat 1D blend states. `Tools/reverse/analysis/studio_animation_contract.py` hashes the recovered C# sources and produces independent binary32 timing traces. Original assets and trace output stay under `.local/reverse/studio-animation`.

Observed base `00` coverage is 287 executable rows out of 288 normal rows, with 411 referenced clips. The remaining row (`m_Lewd_00_01`) stays excluded: conversion rejects it with `Generic loop-pose correction measured but not matched (best max error 0.0023087)` after every measured candidate — including the 2026-09-27 rerun of the component-wise correction with quaternion renormalization and the 2026-10-01 right-local rotation-power re-attribution — failed tolerance. Supplying the original body bundle with `--avatar-bundle` resolves every otherwise unbound hash to `cf_body_lowAvatar` paths absent from both `cf_body_00Avatar` and the converted high-detail skeleton. All 287 executable rows are therefore compatible with the selected high-detail hierarchy: 157 contain only bound tracks, 130 additionally contain low-detail-only tracks, and zero rows have unexplained unbound paths. These optional tracks retain their identities and are skipped, just as in the original high-detail character; they are never guessed onto another bone. This is not coverage of every installed animation mod, H controllers, layered/override controllers, automatic transitions, animation events, root-motion extraction, option-item animation or all dynamic/look-at consumers.

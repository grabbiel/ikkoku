# Renderer, geometry, foundation and generated assets

Audit date: 2026-09-25. This review describes the files present in the working tree, including uncommitted work. It does not certify the whole game as ported. Original-game assets, recovered shader programs and captured evidence remain in ignored `.local/` directories.

Status meanings in this document:

- **Pending**: no executable implementation of the named feature was found.
- **Infancy**: a scaffold, approximation or narrowly exercised prototype exists.
- **Mid-stage**: useful implementation and tests exist, with important coverage or integration gaps.
- **Fully ported**: the explicitly bounded feature is implemented and has relevant verification. This does not extend to adjacent Unity features or all assets. Native infrastructure is identified as such; completion of a native helper is not evidence of original-game parity.

## Critical boundary: production rendering versus diagnostics

The running Maker/Studio renderer uses `Renderer.swift`, `Pipelines.swift` and `Shaders/Toon.metal`/`Outline.metal`/`Post.metal`. These implement the native toon style, selected recovered material-composition controls, and the normal live deformation path. By default they do **not** choose recovered Unity shader programs by source shader identity.

One exception is opt-in (R1/CMT-04, 2026-10-22). With `IKKOKU_LIVE_SOURCE_SHADERS=1` or **View ▸ Live Source Shaders (Experimental)**, Studio source characters draw with the translated original programs in the main pass. The programs are bound from the native binding set and run on live deformed vertices with the live camera and light (`SourceShaderLiveAssembly`, `SourceShaderLiveMaterial`, `SourceShaderLiveEncoder`, `Renderer+SourceShaderLive.swift`). Every material slot whose inputs do not resolve keeps its toon draw and is reported, so a frame never mixes the two silently. With the opt-in OFF, captures are byte-identical to `main`. The path is a measured experiment, not the production renderer. On the controlled fixture it meets the frozen probe's character gates only with capture texture pixels. With natively decoded textures, 1 of 20 slots draws live, and in a real Studio scene the scene globals are unresolved ([renderer reference](../reference/renderer.md#live-source-shader-path-r1cmt-04-opt-in-2026-10-22)).

`OriginalFrameProbe`, `OriginalFrameDiagnostics` and `TranslatedSourceShaderProbe` are separate, synchronous validation paths. They render the original player's already evaluated, frozen geometry with matched camera/material inputs. Their results establish raster/shader-input behavior for that fixture, not native animation, rig, card loading, Studio behavior or live renderer shader parity. The translated probe runs all eight visible shader families in the controlled character fixture. Since the #94 normal-magnitude fix, its full-character silhouette and authored-mip colour gates pass. Per-family hair colour and the production toon image still fail.

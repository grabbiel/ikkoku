How to read this page

Progress needs context.

This is a reviewed snapshot of accepted work, not a live test dashboard. Linked issues may advance after the review date. Detailed references retain their own measured commits, inputs and exclusions.

Mid-stage

A useful implementation exists, with meaningful gaps in coverage, integration, source semantics or verification.

Infancy

A scaffold or bounded executable subset exists; most original behavior or application integration is still missing.

Performance & fidelity

Responsiveness, total latency, memory and GPU work are assessed separately. Public CI cannot certify private original-player or GPU comparisons.

Ikkoku

Small, continuous updates. Traceable evidence.
